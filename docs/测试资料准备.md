# 测试资料准备

源代码不分发赛事原始论文、私人数据库或模型权重。测试分为自包含逻辑测试与需要真实论文几何/内容的集成测试。

直接 `python -m pytest -q` 可执行自包含部分；缺少论文的测试明确跳过，不算通过。用 `python -m pytest -q -rs` 查看缺少哪些资料。420项全部通过的历史记录是在本机已具备官方测试资料条件下取得，不应理解为无资料环境也会执行420项。

如有组委会资料包，将其中 `pdf/` 原文件放到源码根目录 `data/competition/pdf/`，不要改名或修改PDF。常用文件包括：

- `1706.03762v1.pdf` 与 `1706.03762v7.pdf`
- `1706.03762v1_img.pdf`
- `language_understanding_paper.pdf`
- `2005.14165v4.pdf`
- `N19-1423.pdf`

仅复制这些合法原文件即可，不需要作者SQLite文库或私人账号。没有官方资料时可从论文官方来源自行获取相应版本，但扫描版和预设页码应与组委会文件一致，不能把不同版本当作同一测试素材。

本轮在不含官方PDF的公开源码副本中实测并保留首次失败；修复测试中隐式数据库依赖后分别运行无资料检查和补齐原文件的完整检查。具体通过/跳过数量见提交证据，不将skip计为pass。模型实测和工程测试仍分别统计。
