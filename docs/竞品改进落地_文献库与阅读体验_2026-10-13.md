# 竞品改进落地：文献库与阅读体验

本轮根据 40 个相关产品的调研，落实文献管理、导航层级、阅读空间三项高优先级改进。已经更新本地运行网站 `http://127.0.0.1:8765/`。这是第一批落地，不代表调研报告中的全部差距已消除。

## 用户现在可以做什么

1. 打开“文献管理”，先看到整库列表。支持搜索标题、文件名、arXiv 编号、别名、分类和标签；按阅读状态、分类、标签过滤；按标题、页数、版本号排序。不同文献的版本号排序只表示编号，不表示论文发表时间。
2. 点击论文标题或“阅读”直接进入阅读台，沿用已有的按文献保存阅读页码能力。“详情”展开单篇编辑、版本比较、解析、OCR、公式／表格校对、分类及归档恢复等原有工具。
3. 勾选多篇，批量设置阅读状态、分类，或追加标签。追加标签保留原标签；勾选“修改分类”且留空会移至未分类。表头全选仅作用于当前筛选结果；切换过滤保留已选项，明确提示隐藏选择的数量。
4. 可以撤销本页最近一次批量修改。撤销入口不跨页面或刷新持久化；如果其他操作已经改变相同文献的组织信息，会拒绝覆盖并提示刷新。批量更新一次最多 500 篇。
5. 导出所选文献的 JSON 信息清单，包括标题、文件名、标识符、版本、页数、分类、标签及阅读状态。不包含 PDF、笔记或完整备份，也不是新增 RIS 导出。
6. 选择 2—40 篇可直接带入多文献问答范围，无需到阅读页重新勾选。问答仍沿用现有证据核验机制，没有借此声称语义质量提升。
7. 阅读页顶部“专注阅读”收起侧栏和问答区；退出后保留当前页码、问题草稿和已有界面状态。左上角可独立收起／展开侧栏，宽桌面支持拖动“问答栏宽度”。
8. 六个主导航按“发现、管理、阅读、笔记、工作室、复核”组织；双语、图谱、任务和账号可展开“更多工具与成果”。阅读工具栏也有双语入口。
9. 手机文献列表改为逐篇卡片布局；首次教程和各模块帮助保留，文献库与阅读帮助已补充新操作。

## 借鉴关系与边界

文献优先的列表与筛选借鉴 Zotero／Paperpile 的组织思路；减少同级入口、突出当前任务来自对 Consensus、ima 等公开界面的观察。没有复制外部资源、接入付费服务或虚构竞品性能比较。

本轮主要改进现有功能的可发现性和连贯性，并新增真实的批量整理、冲突保护和撤销。仍是单分类字段，不是多对多集合或完整项目空间；没有把这些尚未实现的能力改名当作已完成。

## 数据写入与保护

新增 `PATCH /api/library/organization/batch`。一次事务完成整批写入，保留 PDF 元数据、来源、目录和其他既有字段。逐篇比对客户端展示时的组织信息快照；任何一篇不存在、已归档、数据发生变化或字段无效，整批回滚。撤销同样检查预期值，避免覆盖之后的修改。接口使用现有账户对应的数据库，不越过账号隔离。

真实浏览器测试临时修改了 Attention 两个版本的分类、标签和阅读状态，并通过界面撤销。撤销恢复语义值时会显式写入原本缺省的空分类／空标签／待读字段；验收结束后，只对这两条测试记录核对并移除由测试新增的默认字段，恢复原始 JSON。

最终逐行比对备份，`documents`、`blocks`、`evidence_notes` 三表完全一致：40 份文献、47872 个原文块、2 条原有笔记。PDF 文件没有改写。备份仅用于本轮测试保全，没有用旧库覆盖当前库。

## 验证结果

- 后端全量回归 **176 项通过**，包含新增的批量整理／撤销、整批失败回滚、并发修改冲突、非法输入与账户隔离测试。
- 前端 TypeScript 检查及 Vite 正式构建通过。仍有原有 Mermaid 大分包提示。
- 修改的 Python 文件 Ruff 检查通过；Git diff 空白检查通过。
- 真实 Chrome 浏览器验证：搜索和筛选、隐藏选择提示、批量整理、数据库持久化、撤销、清单下载、多篇带入问答、详情展开、专注模式、问答栏宽度和手机导航。
- 页码清空后输入 7 并按 Enter，实际跳到第 7 页；退出专注后问题草稿及页码保留。
- 390 px 手机视口下页面实际宽度与滚动宽度均为 390 px，文献卡片宽 360 px，无整页横向溢出。没有捕获 JavaScript 页面异常。
- 首轮浏览器脚本在手机导航定位时依赖桌面上显示的文献数量，因手机隐藏数量而超时；修正测试选择器后通过，首次失败记录保留。
- 本地健康检查正常，网页与本地模型均可连接。没有重新评测模型答案，因此不把本轮工程通过解释为答案准确率提升。
