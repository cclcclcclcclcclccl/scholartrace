# 需求验收矩阵

日期：2026-10-11。依据：用户提供的完整赛项文本；尚未核验官网。

本表为后续开发与验收依据。初版建表时所有条目均为“未实现 / 待验证”。2026-10-11 已取得并解压用户提供的赛事资料；实现与验收进展另记于 `执行步骤与当前状态.md`，只有实际记录了验证证据的子项才算通过，不能将首版原型视为全部要求完成。

优先级：P0 = 优先攻克的关键路径；P1 = 省赛前仍必须覆盖的完整功能；P2 = 在必做功能之上的增强。优先级只代表建设顺序，不代表可以不做 P1。

## 阶段验收记录模板

每次实现一个条目后，在单独的运行报告中填写：

```text
需求编号：
代码版本 / 模型 / 配置：
输入文件及来源（官方/补充/自制）：
操作步骤：
预期结果：
实际结果：
原始日志 / 截图 / 导出物：
是否通过及依据：
已知限制与待修复问题：
```

有页面不等于功能完成，有文件不等于结果正确，有一次成功不等于评审期间稳定可用。最终结论必须对应实际证据。
