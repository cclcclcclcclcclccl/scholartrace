# 墨衡预指导修改说明（2026-11-10）

截图预指导总分 90.0。评语原文：“建议下一步把去重升级为向量语义比对并用官方 PDF 跑通三类用例、补一次 Docker 实测与独立网络可用性证明、在评审期间提供不依赖个人主机的托管实例。”

## 1. 正文向量去重

此前正文使用词频余弦，向量仅用于标题。本轮正文也使用本地多语言 MiniLM ONNX 模型：按 PDF 原文块切成最多 600 字符片段，每篇最多均匀抽取 48 段，计算归一化片段向量、正文向量均值余弦与双向片段最佳对齐分数。缓存包含数据库位置、文献 ID、模型标识和原文，避免不同账户或 OCR 更新后复用陈旧结果。

候选阈值 0.92；正文向量相似度达到 0.94 或原有词频高相似，并且原文编号/标题一致时，才提示可能同文。原文编号冲突时禁止同文判断和版本推荐。没有文字时要求先 OCR；模型不可用时分数为 null，不以 0 冒充测量结果。模型分数是启发式，不是重复概率，阈值未经大规模盲测校准。

界面路径：**文献管理 → 文献详情与校对 → 查看结构与版本 → 如何判断重复？查看正文匹配证据**。用户可查看双方页码、正文片段、取样数量，再对照全文变化。归档仍由用户手动操作，不自动合并和删除。

## 2. 官方 PDF 三类验收

依据赛事资料 PDF 第 4 页“三类”指标准 PDF、扫描 PDF、长书籍；标准 PDF 同时覆盖要求的先上传 v7、再上传 v1 的去重顺序。

| 用例 | 实测结果 | 边界 |
|---|---|---|
| Transformer v7 → v1，以及 BERT 对照 | 真实正文向量 0.96617；Transformer 与 BERT 0.87515；推荐保留 v7；BERT 不判为同文 | 这是开发者验收样本，不是总体准确率 |
| 官方扫描件 1706.03762v1_img.pdf | 全部 15 页实际 OCR；各页均提取到文字；恢复标题和 P100 字样 | 没有逐字符人工校对，不能声称全部识别正确 |
| UnderstandingDeepLearning_02_09_26_C.pdf | 541 页、537 页存在原生文字；第 541 页可访问；记录无原生文字页 2、4、10、12 | 全书文字提取，结构只抽查第 1、100、270、541 页；公式、表格准确率未全面标注 |

运行命令：`.venv/Scripts/python.exe scripts/verify_preguidance.py --output artifacts/preguidance-20261110/official-final`。报告包含每个官方文件 SHA-256、逐页 OCR 数量、所有断言和耗时。首轮结果也保留，不覆盖失败或调参前证据。

## 4. 不依赖个人电脑的托管

已准备包含网站、模型、向量、公式环境、评审账号初始化和公共论文的独立 CPU 容器。Docker 白名单排除私人数据库、账号文件、旧提交包和验收归档；所有下载资源校验 SHA-256。新增持久化目录配置：评审账号、任务和笔记可写入魔搭 `/mnt/workspace/moheng-data`；空间重启后保留，但平台转移或删除持久卷仍需另行备份。

优先候选为魔搭创空间的免费 2 核 16 GB CPU，端口 7860。官方 Docker 文档要求绑定阿里云账号并实名认证，需作者本人完成。模型和网站可以同机运行，已有 Linux 容器实测证明；**尚未在作者魔搭账号下创建并验收长期实例，因此此项尚未完成，不能宣称电脑已可关机。**

Hugging Face 当前概览说明计算型空间新建需要付费计划，不以 CPU Basic 小时价为零推断整个方案免费。本轮不购买套餐、不调用付费模型，也不使用 GitHub Actions 长期托管网站。
