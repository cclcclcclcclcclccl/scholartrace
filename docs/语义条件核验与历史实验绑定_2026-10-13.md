# 语义条件核验与历史实验绑定

日期：2026-10-13。当前仍是持续改进中的本地科研工作台。本轮完善问答证据链和实验历史版本绑定，没有更换付费模型，没有执行模型训练，也不表示全部赛事质量项通过。

## 已实现的改进

### 历史实验版本可明确选择

以前分析 CSV 时，系统总是读取设计卡的最新版。若实验是在旧版条件下执行、随后才上传数据，就可能绑定错误的指标、种子或对照。

现在进入“科研工作室 → 重复实验统计与误差棒”，选择关联设计卡后，可以明确选择“实际执行的设计版本”。保存前显示所选版本的指标、种子和对照。后端按该版本做一致性检查并保存快照；选择期间其他页面又修改设计，也不会把本次选择悄悄切换到新版。

刷新设计列表会重新读取版本，并默认选中读取时最新版，用户应核对后再提交。旧 API 调用未指定修订号时仍兼容最新版，但会明确提示没有显式选择。不存在的版本拒绝保存；其他账号的设计卡不能关联。

该功能保留的是用户声明的实验条件和上传数据，并未证明数据真实性，也不会自动执行训练。

### 问答支持片段可以展开检查

支持性审核现在必须返回原引用中的具体连续片段，服务器检查该片段是否确实存在。网页可展开“查看支持片段（模型初判）”，完整原引用和原文定位仍可用。伪造支持片段、越界审核项不接受。

生成顺序调整为先选择证据编号，再写论断。补充回答前要求列出未回答的子问题，以减少重复和漏项。对初始化、权重合并、跨任务批处理、精确/近似方法这几类概念增加有限的中英检索覆盖；每个触发概念保留一个词法证据候选，之后继续沿用相邻段落和表头处理。没有写入论文特定答案或块 ID。

增加一些可以直接观察的保守拒绝规则：

- “未观察到增益”不能不加实验范围就写成绝对“没有增益”。
- “最高快 3 倍”不能直接写成固定“快 3 倍”。
- 运行时间线性、最优性等表述需要自己的引用支持。
- HBM/SRAM 等明确存储层级不能只出现在别的证据中；中英文相邻也要检查。
- 任务切换、权重合并和同批混合任务需要区别；否定句不能被肯定句规则误拦。

这些都是局部保护规则，不是通用语义证明。模型仍可能把真实引用用于不恰当的结论。模型自报的“没有找到/未报告”不再直接作为论文事实展示，只提示回答可能未覆盖完整内容。

支持片段存在、数字出现、关键词通过，均不能单独证明推理正确。后续需要面向子问题的语义完整性评价和独立标注，尤其要统计误答与漏答，而非只追求分数。
