# 逐项问答与部分结果保留

本轮继续处理复合问题漏答、引用错配与表格误拒答。使用本机 Qwen3-4B，没有新增付费接口或运行依赖。用户原 PDF、笔记和既有评测结果保留。

## 新增可见功能

提问包含多个独立句子时，系统按原句形成最多四个处理项。超过四项的剩余文字并入最后一项，不直接丢弃；“不要混用”“保留限制条件”等约束尽量并回前一项。它不是通用语义分解器，一句话内多个字段仍可能属于同一项，用户应核对清单是否覆盖自己的要求。

每项单独检索，选择最多两段原文后生成回答，再进行数字、原句存在性、支持性和条件检查。服务器保存选中段落全文，不依赖模型重写原文。每项最多五条候选回答，总计最多二十条进入校验。模型处理失败时保留其他项的结果；没有生成有效答案也会保留未解决状态。

问答页和“任务与成果”新增“逐项回答情况”。标记“有回答”只表示至少一条论断通过初筛，不表示该项完整或正确。未解决项显示“本轮未形成通过核验的回答；不表示论文没有答案”。Markdown 和 JSON 导出保留这些状态，避免分享时只留下看似完整的答案。

多篇比较仍先按文献划分范围，逐篇使用原有问答路径，避免将跨文问题直接拆成某一篇不适用的条件；并未宣称本轮已经验证跨文子问题分配的完整性。

## 修复的明确工程问题

1. **表号误拒答。** 表格数据块和表头中没有表号，答案一旦写“表 1”就被数字存在性检查拒绝。现在为几何位置明确的近邻表题附加独立原文锚点，远处或不唯一的表题不自动关联。没有放宽数字检查；网页按钮统称“核对表格上下文”。
2. **同一问题的第三字段丢失。** 新分项流程早期限制每项两条，导致 ViT 的层数和隐藏宽度保留，第三个参数量被截掉。现在每项最多五条，并有三字段保留测试。
3. **生成与核验引用不同。** 逐项召回的完整段落及表格上下文现在同步到统一证据列表，避免生成时看到完整内容、核验时却只用旧截断段落。
4. **定义段被重复表格挤出。** 精确/近似方法的概念检索扩大词法候选，再优先定义性段落，不向模型塞入全部候选。
5. **无依据的“没有比较”断言。** 只有架构描述的来源不足以支持“论文没有比较”；增加保守规则并用明确否定原文作反例测试。该规则仍不是全文事实证明。
