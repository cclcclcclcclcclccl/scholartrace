# 研究项目工作区与真实验收

本轮把竞品调研中“资料、阅读、任务和输出彼此分散”的缺口落实为持久化研究项目。参考已有竞品调研的集合整理与课题工作流思路；本轮没有重新采集竞品访问量。科研可信性仍以原文核对和独立评测为准。

## 现在怎么使用

本机主页：<http://127.0.0.1:8765/>。刷新页面后，左侧第一项为“研究项目”。如果本机服务未启动，双击根目录 `启动研证.cmd`。

已经建立起步项目“注意力机制：版本与效率证据”：<http://127.0.0.1:8765/#project=e12fc354b4d7490480f068685b4eed80>。该项目属于默认本机研究空间，用于熟悉产品流程，不代表已确定最终竞赛选题或完成科学实验。

1. 打开“编辑目标与文献”，填写研究问题、检索候选论文、勾选并保存。一个项目最多关联 500 篇论文，同一篇论文可属于多个项目，不改变文献库原有分类。
2. 在“项目文献”阅读已加入论文；在“关联笔记”查看这些论文已有的非归档笔记，点击“核对原文”定位对应版本和页码。
3. 点击“使用项目文献提问”，自动进入多篇问答并带入范围；点击“进入项目工作室”，自动带入目标与文献。当前这两个入口支持 1—40 篇可用文献，具体工具仍遵守自身更小的限制，例如矩阵最多 6 篇。
4. 从项目发起的问答、综述、方案、证据矩阵及工作室图稿／CSV 图表自动关联到项目；后台任务显示在“最近任务”。任务仍在运行时可离开页面，返回项目或点击刷新查看新成果。
5. “研究成果 → 收纳已有成果”可关联其他历史输出，包括实验设计、执行预检和实验统计。移出成果只解除关联，原成果继续保存在“任务与成果”。
6. 可归档／恢复项目、复制本机项目链接或导出 JSON 项目摘要。摘要包含目标、文献清单、关联笔记、成果索引和最近 25 个任务，不含 PDF 文件与成果全文。

起步项目保留 2 篇 Attention 论文（v1、v7）、2 条已有证据笔记、3 份新增成果和 1 个真实完成的后台任务。新增成果为一份实际模型问答、一张手写流程脚本渲染图和一张本地模型生成的方案图。没有虚构实验结果。

## 实现及数据边界

- 新增 `projects`、`project_documents`、`project_artifacts` 表；全部使用当前账号对应的 SQLite 数据库。原有 PDF、原文块、笔记和成果内容不改写。
- 项目笔记按所关联论文聚合，因此同一篇论文的笔记会显示在多个项目中。移出文献改变显示范围，不删除原笔记。
- 问答和研究任务入口先校验项目状态及来源范围。项目问答／综述等来源范围为空时拒绝处理，不自动转为全库；范围外或归档论文不能用于新的项目取证。
- 自动收纳的成果保留生成时项目名称、目标、项目成员快照和请求的 `source_document_ids`。纯主题图稿没有进行文献检索时该来源列表为空，不能把项目成员清单当作引用证据。
- 项目配置用版本号进行并发校验，后台自动加入成果也会增加版本号。旧页面保存返回 409，并保留当前页面草稿，用户可以复制草稿后刷新再应用；刷新不会自动合并冲突。
- 已提交的后台任务按照提交范围继续执行；运行期间归档项目不会丢掉正在生成的结果。成员调整不会追溯重写已有任务或历史成果。
- 没有加入付费 API 或更换本地模型，没有增加 npm／Python 依赖。

## 验收证据

目录：`artifacts/project-workspace-2026-10-14/`。

- `before.sqlite3`：操作前一致性备份；未使用旧备份覆盖当前数据库。

- `project-export.json`：浏览器下载的最终项目摘要；`starter-project.json`：起步项目 ID 和目标。

复查命令：`.venv/Scripts/python.exe -m pytest -q`；前端目录 `npm run build`；根目录 `node scripts/check_projects_ui.mjs` 和 `node scripts/check_project_job_ui.mjs`。浏览器脚本实际写入本机起步项目并调用本地模型，会新增验证成果；不要把它当成只读巡检。

## 还没有完成的部分

- 实验设计／预检／统计暂需手动关联；项目笔记不是独立笔记空间；配置草稿没有跨刷新保存。
- 项目详情通过重新进入或“刷新项目”获取后台更新，不是多人实时协作系统。
- 项目链接只在可访问本机服务且属于同一账号时有效，没有公网分享权限或完整项目打包迁移。
- 科研工作室仍偏长表单；写作与图形局部编辑、标准引文互通、独立问答／翻译／解析评测，以及版本变化影响的召回／误报评测仍需继续推进。
- 本轮补上科研任务组织流程，未把它当作独有算法创新；竞赛亮点仍需围绕真实证据变化及复核收益给出可验证结果。
