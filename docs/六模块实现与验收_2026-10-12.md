## 环境、数据与复现

- 本机：Windows，Python 3.12，React/TypeScript，FastAPI/SQLite，llama.cpp b11552 Vulkan，Qwen3-4B Q4_K_M，8192 上下文；向量模型 multilingual MiniLM L12，ONNX 量化版，384 维。
- 数据：39 份赛事资料 PDF，1,986 页、47,373 个原始块；原始 PDF 和两条已有证据笔记保留。测试用户、OCR 专项与追踪专项使用隔离数据库。
- 地址：`http://127.0.0.1:8765/`。这是本机访问地址，不是公网评审地址。
- 入口：根目录 `启动研证.cmd` / `停止研证.cmd`。异常进程由守护程序恢复，长任务由数据库记录进度。
- 主要验证命令：`python -m pytest -q`、前端 `npm run build` / `npm audit`、`node scripts/check_full_workbench.mjs`、`node scripts/check_completion_ui.mjs`、`python -X utf8 scripts/check_completion_workflows.py`。
- 原始结果在 `artifacts/full-workbench/`；该目录不入 Git。脚本会明确标注开发实测，并保留失败。`--retry` 只补测上次失败项，`--local-only` 不请求外部接口。

## 检索开发对照与质量边界

同一组 10 道自制开发问题，在 Transformer v1 上的出处片段 Hit@5：BM25 0.30，单向量 0.40，混合 0.50，加中文问题英文转换后 0.80。原始记录为 `retrieval-ablation.json` / `query-translation-eval.json`。查询转换是在同一开发集上调优的，不能表述为独立测试集 80% 准确率，更不等于回答正确率。向量输入每段截断为 256 tokens，长段尾部信息仍可能漏召回。

本轮真实修复包括：PDF 单词换行与弯引号引文匹配、逐篇证据编号混淆、模型使用错误绘图字段名、完整翻译的数值/公式占位丢失、图谱容器 CSS 冲突、数字横轴被等距绘制、引用短句被误判丢失。修复保留原始文本、坐标、数值与历史成果。

下一阶段优先关闭 A04/A05/B01/B04/B06/G10 的质量缺口，再做创新效果对照、公网稳定性和最终材料。不能用进一步增添菜单替代这些质量验证。

## 新问题首轮失败与修复记录

新增 `tests/acceptance_questions_v1.json`：8 道事先写定问题，包括训练预热、标签平滑、权重共享、BERT 两种规格/语料/替换策略，以及两个缺证据问题。每题预先标注原文块；首次结果和后端源码 SHA-256 存在 `acceptance-v1.json`。机械检查仅 3/8 通过，暴露多部分漏答、无关背景充当答案、引文抄录格式导致丢失、中文查询漏召回等问题；这份首次失败没有覆盖或删除。

随后修复为：英文关键词检索、服务器按证据 ID 取真实引用、一次有界的漏答补充、逐条支持性与问题相关性校验。实测还发现模型解释重复直到 JSON 截断，进一步约束核验解释为固定类别。最终同题开发回归 8/8 通过机械检查，记录为 `acceptance-after-fix-final.json`，中间各轮仍保留。BERT 两种规格的八个数字、语料词数、替换比例与两个拒答逐条检查了真实输出。

**8/8 是暴露问题并修复后的同题开发回归，不是独立泛化准确率，也不是官方或人工评审结果。** 后续须另冻结未用于改动的新题集。代码中的模型支持性核验仍是初筛，不能替代科研人员对原文与条件的核对。

## 公式识别追加验证

本地 RapidLaTeXOCR 0.0.9（ONNX CPU，2 线程）使用独立 NumPy 1.26 环境，避免影响主应用；新增 `requirements-formula-lock.txt` 与可重跑安装脚本。模型来自 RapidAI 官方 GitHub release v0.0.0，总计约 179 MB，固定 SHA-256。包自带 LICENSE 和原模型项目均为 MIT；PyPI 元数据写作 Apache-2.0，与实际包 LICENSE 不一致，分发时以实际许可文件和上游确认记录为依据。

浏览器实测原生论文自动检测注意力公式候选、保存并重开、扫描件拖动框选均完成，KaTeX 渲染与原图已视觉核对。注意力公式中的 QK 转置、根号下 d_k、softmax 与乘 V 均保留。前馈网络公式的一次直接试验出现额外左括号，系统保留候选并标注括号检查警告，不自动修成猜测值。该失败样例说明目前不适合声称公式识别全正确。结果为 `formula-report.json`、`formula-native.png`、`formula-scan.png`。
