# 稳定性与阅读体验改进

日期：2026-10-11。用户反馈：本机网页拒绝连接，并授权自主改进作品。

## 故障事实与修复

检查时端口 8081 的本地模型仍在运行，8765 没有监听进程；这解释了截图中的 ERR_CONNECTION_REFUSED。日志中缺少足以确定退出原因的证据，不能断言是用户操作或某一次崩溃造成。旧启动脚本只负责启动一次，没有异常退出恢复。

新版启动器通过 Windows 的独立后台进程标志启动守护进程，使其脱离临时命令的作业生命周期。守护进程管理网页与模型，进程退出后自动退避重试；模型正在加载、返回 HTTP 503 时，不会重复创建模型进程。并发启动有互斥，重复启动复用现有服务。停止时核对可执行文件路径与创建时间，避免 PID 复用误杀。

实测完整停止／重启时还发现并修复了一个 Windows 边界问题：查询已经退出的进程会让 PowerShell 返回失败码。现在重复停止以及停止后的再次启动均正常。

未配置开机自启。电脑重启后双击 `启动研证.cmd`。仍仅监听 127.0.0.1，未做公网部署或长时间可用性承诺。

## 使用体验改进

1. 实时连接状态：每 5 秒检测；断线显示操作提示并自动重试。恢复后重新加载文献和原文，保留当前页面的问题输入及阅读页码。
2. 长文阅读：显示 PDF 内嵌目录，支持标题搜索和章节跳转；没有内嵌目录的文献会明确说明。没有伪造生成章节。
3. 阅读缩放：75%–200%，相对于适合当前面板宽度；超宽内容在阅读器内部滚动。
4. 原文文字选择：原生 PDF 文本层支持选择复制；扫描原图仍依靠已有 OCR 证据定位，本次没有生成扫描件可选文本层。
5. 阅读进度：本浏览器按文献保存最后页码，刷新与切换后恢复。不会跨设备同步，也没有保存聊天历史。
6. 引文核对：回答卡片直接呈现已检查存在的引用原句；点击证据将原文块滚动到阅读器可见区域，重复点击也可重新定位。
7. 异步隔离：切换论文、离开当前页面或切换复核目标时停止等待，忽略过期结果。停止等待不承诺立即停止后台推理。
8. 样式隔离：只保留 PDF.js 文字层必需样式，避免其完整查看器中的侧栏样式覆盖应用界面。

## 验证与证据

- 原有真实 PDF 集成测试：12 项通过；测试框架有一条既有的弃用提示。
- 前端 TypeScript 检查与生产构建通过。
- 浏览器原有流程：真实本地模型问答、出处定位、笔记保存、两条版本复核及手机布局通过。
- 故障注入：结束已确认属于本项目的网页进程后，约 4.165 秒恢复；39 份文献与 2 条笔记一致；重复启动复用守护进程。此数值是本次本机实测，不是服务等级承诺。
- 生命周期：停止后网页和模型端口都关闭；重复停止成功；再次启动后网页及本地模型可用，文献列表一致。
- 长文阅读：官方 541 页资料的 181 条内嵌目录可用，跳到第 540 页后刷新恢复；缩放、文字选择、证据滚动、断线恢复、旧请求隔离及手机布局已纳入浏览器验收。

详细结果位于 `artifacts/inspection/recovery-check.json`、`artifacts/inspection/lifecycle-check.json`、`artifacts/browser/results.json` 与 `artifacts/browser-quality/results.json`。截图在相应浏览器目录下。资料、数据库、模型与这些机器生成的产物保留在本机，不纳入源码提交。
