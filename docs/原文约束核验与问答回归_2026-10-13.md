# 原文约束核验与问答回归

本轮继续处理科研问答的漏答、引用错配和表格误拒。保持零元、本机 Qwen3-4B-Q4_K_M；没有接入付费服务、下载替代模型或更改原 PDF。当前为六模块可运行工作台，尚未完成所有赛项质量验收。

## 用户可见的变化

- 未回答项区分“未生成可核验回答”“候选回答未通过初筛”和处理失败。找到候选原文时，可直接打开对应 PDF 页；候选材料明确标记为未经支持性确认。
- 成果重开保留上述状态和原文入口。Markdown 导出包含未解决项的候选文献 ID、页码和文本块 ID。
- 成果页长引用默认折叠，支持片段和 PDF 定位仍可直接使用，避免同一个多行表格重复占据大段页面。
- 问答模块帮助增加未回答项的使用方法及复合问题等待说明。

## 实际定位和修复

1. **初始化解释错误。** 基线生成把 LoRA 的 A、B 都写成随机初始化，随后被模型审核拒绝，造成原因漏答。对相同输入比较后，在复合问题的逐项生成及逐条审核中开启本地模型推理；单问题和其他模块沿用原配置。推理预算上限为每次 3600 token，实际等待变长，不是无成本改进。
2. **表格支持片段被模型改写。** 中间回归中，模型把 PDF 的 `ViT-Base / 12 / 768 / …` 改成 `ViT-Base · Layers: 12`。后者不是原文，严格引文匹配正确拒绝它，却导致原本正确的答案丢失。现在服务器从真实引用构造连续原文候选，结构化输出约束模型从中选择支持片段；句组、整段和长段落的重叠片段均不拼接跨段内容。仍检查返回片段确实存在于所引来源。
3. **数字仅在大段原文中出现。** 以前主要核对数字是否存在于完整引用，模型可能选一个不含这些数字的支持句。现在支持片段也执行数字复核，表格仍携带已有的独立表头/表题出处。数字检查不等价于证明对象和数值对应正确。
4. **截断和单条审核失败。** 本地模型返回非正常结束状态、空内容时拒绝接收。某条支持性审核失败只拒绝该候选，保留其他已核验的回答；没有将失败视为论文未报告。

## 对照实验和保留的失败

首先以相同检索材料比较原有提示、简短的“先摘原句再作答”提示、每次单独提供一个出处。后两者仍产生错归因、无关背景和重复回答，因此未接入产品。记录为 `extraction-comparison.json`、`isolated-extraction-comparison.json`。

`reasoning-comparison.json` 比较同一本地模型开启推理的生成结果，保留原始响应、token 使用与耗时。这个初步比较使用 JSON 对象输出；随后再回到产品的原有 JSON Schema 约束和完整核验流程验证，未把初步结果直接当作产品通过证据。

初期产品回归 `release-v4.json` 为 3/4、`release-v5.json` 为 2/3，后者包含 ViT 表格退步。`table-regression-stages.json` 记录了生成正确而支持片段被改写的阶段证据。失败文件全部保留，没有覆盖或修改冻结题集的评分词。

最终同版本回归见 `final-v4.json`、`final-v5.json`。所有问答分数是开发题的关键词、出处存在和标注召回检查，**不是独立准确率、语义正确率或官方测试成绩**。同一模型生成和审核仍有相关错误，必须结合逐句核对。

| 固定题集 | 上一轮最终 | 本轮最终 | 逐句检查 |
| --- | --- | --- | --- |
| v4，四题 | 2/4 | 3/4 | LoRA 初始化及零增量原因恢复；GPT-4 未公开精确参数量拒答。FlashAttention 已区分精确原版与近似稀疏扩展，但内存层级仍漏答。LoRA 合并题机械通过，仍出现“无需额外计算资源”的过度概括，以及恢复原权重和加入新适配矩阵的措辞混淆，不能判语义通过。 |
| v5，三题 | 2/3 | 3/3 | 图文输入/文本输出、ViT 三个规格＋未解决单次测量、LoRA 冻结原权重/训练低秩矩阵/部署合并均在本次输出中保留。仍有重复语句。 |
| 旧 v3，六题 | 上轮完整回归 5/6 | 5/6 | 规格、优化器/批大小、分类头、分辨率条件和未知单次结果检查通过；位置嵌入题保留可学习一维/未观察到二维方案增益的含义，但中英混用仍未命中冻结模式，不修改评分词。 |

最终 v4 耗时约 **3—64 秒/题**，v5 约 **5—42 秒/题**。上一轮对应约 3—20 秒、5—12 秒。更长的推理与审核换来部分漏答改善，但不能证明普遍语义提升；需要继续做独立评估和延迟优化。v4/v5 冻结文件未修改。

旧 v3 补查耗时约 7—70 秒/题，报告为 `final-v3.json`。分类头题的额外解释仍应按来源逐句复核，不能把机械通过解释为每句话都正确。

## 尚未达标的部分

推理模式不能代替更强模型或独立评审。FlashAttention 的完整内存层级回答仍有漏项；LoRA 任务切换、恢复原权重和加入新适配矩阵的叙述仍需核对，机械检查可能放过措辞混淆。重复回答、推断范围和跨语种理解仍需进一步评测。本轮没有声称零幻觉、全部功能质量达标或保证获奖。

本轮对应问答与引用 B01/B03/B05、原文定位 B02、成果导出 F05 的局部验收。其他待办仍遵循总验收矩阵，包括未参与调优的新题、复杂解析、独立创新收益验证、外部追踪稳定性、公网评审地址及提交材料。
