## 你可以直接检查的操作路径

1. 打开 `http://127.0.0.1:8765/`。服务未启动时双击项目根目录 `启动研证.cmd`。
2. **研究项目 → 已有项目 → 下载完整成果包**，解压后先读 README 和 manifest，再查看 artifacts 中的完整成果。
3. **更多工具与成果 → 任务与成果**。记录超过 50 条时出现“加载更早任务”；阅读台的“查看后台问答”独立筛选问答任务，不受其他任务数量影响。
4. **证据笔记 → 编辑观察**。如果遇到冲突，保留草稿，点击“查看最新笔记，保留草稿”；核对后点击“已核对最新笔记，保留草稿继续编辑”，再保存。不要在没有核对差异时确认。
5. **版本复核 → 选择另一版本 → 检查证据变化**。超过本批范围或预算的条目可继续复核；“导出复核报告”保存累计结果。“不确定”和“未检查”都不等于没有变化。
6. **版本复核 → 复核已生成成果 → 任务与成果 → 打开完成报告**。超过 30 条时在报告里“继续下一批成果复核”；新报告保存为独立成果。
7. 需要再次备份时，在项目根目录运行 `.venv\Scripts\python.exe scripts\backup_databases.py`。输出在 `data/backups/`，本轮目录为 `20261014T125123214880Z`。备份包含私有账号数据，请保存在本机；PDF/模型文件需另行备份。脚本没有自动恢复功能；逐库一致不代表多个账号之间是同一瞬间快照。
