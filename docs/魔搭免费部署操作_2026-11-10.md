# 墨衡免费云端部署：本人操作清单

目标是让评审完整网站不依赖个人电脑，不购买服务器或模型 API。当前仍未上线长期云实例；在云端验收之前继续保持原电脑开机联网。

## 第一步：注册与实名认证

1. 打开 https://modelscope.cn/ 注册、登录魔搭账号。
2. 按 https://www.modelscope.cn/docs/accounts/aliyun-binding-and-authorization 绑定你自己的阿里云账号。
3. 根据平台提示在阿里云完成实名认证。身份证、手机验证码、支付宝/银行卡等身份信息由你本人在官方网页输入，不发给助手。
4. 不开通付费服务器、GPU 或订阅；本任务只使用魔搭自带的免费 CPU 资源。

实名认证是魔搭 Docker 空间的官方前置要求；助手不能代替你完成身份验证。

## 第二步：创建空间

1. 打开 https://modelscope.cn/studios/create 。
2. 选择“编程式创建”，SDK 选 **Docker**。
3. 名称可用 `moheng-review`，中文名“墨衡科研助手”；可见性选公开，便于评委访问。
4. 资源选择 **platform/2v-cpu-16g-mem**，即免费 2 核 CPU、16 GB 内存。若界面显示费用、要求订阅，停止购买并保留页面信息；不要改选收费配置。
5. 创建后把空间网页链接发给助手即可；不要发送密码或访问令牌。

## 第三步：上传已经准备的文件

1. 解压同目录 `02_魔搭免费云端部署包.zip` 到一个新文件夹。
2. 若使用“快速创建并部署”，上传解压后的项目文件夹，平台读取根目录 `ms_deploy.json`。
3. 若使用自定义创建，进入空间“空间文件 → 添加文件 → 上传文件”，保留文件夹层级上传全部内容。
4. 确认空间根目录直接出现 Dockerfile、README.md、ms_deploy.json、backend、frontend、scripts、deploy；不要再套一层 ZIP 文件夹。
5. **不要上传 `04_仅本人查看_云端密钥.txt`、旧完整作品包、个人数据库或历史验收归档。** ZIP 已排除这些文件。上传 ZIP 本身而不解压也不会自动启动网站。

## 第四步：设置评审密码并上线

1. 进入空间“设置 → 环境变量”，添加 `MOHENG_REVIEW_PASSWORD`。
2. 在本机打开 `04_仅本人查看_云端密钥.txt`，将其中的值复制到平台秘密变量输入框。该值沿用既有评审专用密码，不能写进公开 README。
3. 点击“上线/立即发布”，查看构建日志和运行日志。第一次需要下载公开模型，可能等待较久。
4. 日志不要出现哈希不一致、模型加载失败或缺失密码；出现错误时把已遮盖敏感值的错误信息交给助手处理，不跳过资源校验。

## 第五步：上线验收与固定入口更新

1. 打开空间的实际应用地址（不是源码页）。健康接口 `/api/health` 应显示 `model_available: true`。
2. 登录名为 `reviewer`，使用上一步秘密变量密码。默认两篇演示论文是 Transformer v1/v7。
3. 问 v1 “训练用了哪些 GPU？”，检查 P100 和引用页码；进入文献管理查看正文向量去重，确认建议保留 v7。
4. 关闭手机 Wi-Fi、使用移动网络再次访问。助手另从 GitHub 云端检查这个新地址。
5. 新云端实例完整验收通过后，才将已提交的固定 GitHub Pages 入口指向云端，同时更新评审账号说明。届时个人电脑可以关机；现在还不可以据此关机。

## 已知边界

免费资源没有连续可用性承诺；模型在两核 CPU 上较慢。当前 Docker 已在 GitHub Linux 云端真实启动和问答验收，但魔搭平台实际构建、域名访问和资源排队情况必须在你的账号下验收后才能确认。数据默认在容器内部，重建可能丢失，演示之外的重要成果必须导出。
